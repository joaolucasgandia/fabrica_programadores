
# Material Complementar EAD

Bem-vindo ao repositório oficial de **Material Complementar EAD**! Este espaço foi criado para que os alunos possam compartilhar e organizar as atividades propostas pelos professores ao longo dos módulos do curso.

---

##  Estrutura do Repositório

O repositório está organizado em três pastas principais, uma para cada módulo do curso:

```
Material-Complementar-EAD/
├── modulo-1/
├── modulo-2/
└── modulo-3/
```

Cada pasta corresponde a um módulo específico. Os alunos devem depositar suas atividades na pasta correspondente ao módulo em que estão matriculados no momento.

---

##  Como Contribuir

Para depositar suas atividades, siga os passos abaixo:

### 1. Faça um Fork do Repositório
Antes de qualquer coisa, você precisa criar uma cópia deste repositório na sua conta do GitHub. Para isso:
- Clique no botão **Fork** no canto superior direito desta página.
- Isso criará uma cópia do repositório no seu perfil.

### 2. Clone o Repositório Forkado
No seu terminal, clone o repositório forkado para o seu computador:
```bash
git clone https://github.com/seu-usuario/Material-Complementar-EAD.git
```

### 3. Adicione suas Atividades
- Navegue até a pasta do módulo correspondente (ex: `modulo-1/`).
- Adicione seus arquivos de atividade (PDF, DOC, imagens, etc.).
- **Importante:** Nomeie os arquivos de forma clara, incluindo seu nome e o título da atividade (ex: `Joao_Silva_Atividade1.pdf`).

### 4. Faça o Commit e Push
Após adicionar os arquivos, faça o commit e envie para o seu repositório forkado:
```bash
git add .
git commit -m "Adicionando atividade do módulo X - [Seu Nome]"
git push origin main
```

### 5. Envie um Pull Request (Opcional)
Se desejar que suas atividades sejam revisadas ou integradas ao repositório principal, você pode abrir um **Pull Request**:
- Vá até o repositório original e clique em **New Pull Request**.
- Descreva brevemente as alterações e envie.

---

##  Regras e Boas Práticas

- **Organização:** Mantenha os arquivos dentro da pasta correta do módulo.
- **Nomenclatura:** Use nomes descritivos e padronizados para facilitar a localização.
- **Atualização:** Sempre faça um `git pull` do repositório original antes de enviar novas atividades para evitar conflitos.
